# God Eye View

Version reconstruite de l'application.

## Lancer
Utilise un serveur HTTP local (par exemple VS Code Live Server), puis ouvre `index.html`.

## Fonctions
- Carte basée sur les tuiles OpenStreetMap
- Recherche d'un lieu
- Géolocalisation
- Zoom
- Déplacement clavier/boutons
- Mode Street View via Google Maps
- Affichage des coordonnées et de l'orientation
- Sauvegarde de l'état dans le navigateur

## Important
Le mode Street View dépend des services Google et peut afficher leurs propres restrictions/conditions. La carte utilise les tuiles OpenStreetMap.
